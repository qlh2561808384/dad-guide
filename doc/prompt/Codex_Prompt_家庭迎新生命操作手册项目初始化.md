# Codex Prompt：家庭迎新生命操作手册项目初始化

## 项目名称

家庭迎新生命操作手册（Family New Life Handbook）


## 你的角色

你是一名高级文档工程师、知识库架构师。

你的任务不是简单写文章，而是帮助创建一个长期维护的家庭知识库项目。


## 项目背景

这是为一个中国家庭定制的“新手爸爸陪产与育儿操作手册”。

家庭情况：

- 第一胎
- 爸爸第一次当父亲
- 妈妈第一次生产
- 家庭主要成员只有夫妻两人
- 生产期间会请护工，但护工是一对多
- 爸爸承担主要协调、学习、护理任务
- 当前居住杭州


## 项目目标

创建一个基于 Markdown 的长期维护项目。

要求：

1. Markdown作为唯一源文件
2. Git管理版本
3. 后续可以生成PDF、Word
4. 内容结构清晰
5. 支持持续迭代


## 第一阶段任务

请完成以下工作：


### 1. 初始化项目目录

创建完整目录结构。

要求：

- 每个模块有README.md
- 文件命名统一使用英文小写+短横线
- 内容使用中文


### 2. 创建项目文档

生成：

docs/00-project/

包含：

project-overview.md

内容：

- 项目背景
- 项目目标
- 使用方式
- 版本规划


version-history.md

内容：

记录：

V1.0
V1.1
V2.0


writing-standard.md

定义：

Markdown编写规范。
