# 第一部分：Prompt 命名规范升级

## 一、命名规范

以后所有 Prompt 文件统一采用：

PR-XXXX_<名称>_V<版本>.md

例如：

PR-001_项目初始化_V2.0.md
PR-008_Phase0最终收尾_Freeze_V1.0.md
PR-009_第一卷章节架构设计_V1.0.md

禁止继续使用：

- Codex_Prompt_
- Phase1_M1_...
- Milestone 写入文件名

## 二、目录职责

目录负责分类：

prompts/
├── initialization/
├── volume-01/
│   ├── 01-outline/
│   ├── 02-content/
│   ├── 03-review/
│   └── 04-release/
├── volume-02/
└── ...

文件名负责唯一身份：

PR-XXXX_<名称>_V<版本>.md

项目管理信息（Phase、Milestone、Volume、Stage）统一维护在 prompt-index.md。

## 三、标题规范

Prompt 文档标题统一采用：

Version：Vx.x

不要继续使用：
