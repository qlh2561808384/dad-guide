## 七、更新 ADR-006

更新：

```text
docs/00-project/decision-records/ADR-006-prompt-archive-and-status-model.md
```

在状态模型中补充：

```text
Reserved
```

建议完整状态模型为：

- Draft
- Testing
- Approved
- Reserved
- Archived
- Deprecated

明确区分：

### Draft

存在实际 Prompt 草稿文件，但尚未通过审核。

### Reserved

编号保留，但不存在有效 Prompt 文件，不得重新分配。

### Archived

历史版本归档，仍具有审计价值。

### Deprecated

Prompt 已废弃或被替代，不再执行。

不得将“没有文件的编号”登记为 Draft。
