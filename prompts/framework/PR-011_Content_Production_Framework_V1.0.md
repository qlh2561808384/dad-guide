## Prompt

### 一、背景

《家庭迎新生命操作手册》项目已完成工程治理（PR-001～PR-010）。

从 PR-012 开始进入正文生产阶段。

本 PR 的唯一目标是建立整个项目统一的 **Content Production
Framework**，供后续八卷内容长期复用。

本 PR **禁止生成任何正文内容**。

------------------------------------------------------------------------

### 二、任务目标

建立整个项目统一的内容生产框架，包括：

1.  Content Production Framework
2.  Writing Handbook
3.  Medical Reference Handbook
4.  Style Guide
5.  Review Handbook
6.  Release Handbook

要求一次完成，不保留 TODO，不拆分后续架构任务。

------------------------------------------------------------------------

### 三、输出内容

#### Part 1：Content Production Framework

建立整个项目统一内容生产流程，包括：

-   Content Flow
-   Review Flow
-   Release Flow
-   Volume Flow

形成统一生产框架。

------------------------------------------------------------------------

#### Part 2：Writing Handbook

制定统一正文写作规范，包括但不限于：

-   章节结构
-   标题规范
-   固定章节模板
-   爸爸行动项
-   妈妈注意事项
-   医学知识模块
-   操作步骤
-   Checklist
-   FAQ
-   家庭记录模板
-   Mermaid 图规范
-   表格规范
-   风险提示规范

要求八卷全部遵循。

------------------------------------------------------------------------

#### Part 3：Medical Reference Handbook

制定统一医学引用规范，包括：

-   引用来源等级
-   推荐引用来源
-   引用格式
-   引用位置
-   医学免责声明

统一适用于全书。

------------------------------------------------------------------------

#### Part 4：Style Guide

制定全书统一写作风格，包括：

-   面向第一次当爸爸的读者
-   通俗易懂
-   可执行
-   不制造焦虑
-   操作优先
-   保持出版级表达

------------------------------------------------------------------------

#### Part 5：Review Handbook

制定统一 Review 规范，包括：

-   内容一致性
-   医学准确性
-   引用完整性
-   Checklist 完整性
-   Mermaid 检查
-   重复内容检查
-   AI 幻觉检查
-   可执行性检查

作为后续所有章节统一验收标准。

------------------------------------------------------------------------

#### Part 6：Release Handbook

制定统一发布规范，包括：

-   Release 流程
-   CHANGELOG 更新规范
-   STATUS 更新规范
-   Release Note 模板
-   版本管理规范

------------------------------------------------------------------------

### 四、边界

本 PR：

-   不生成第一卷正文
-   不修改 PR-001～PR-010
-   不修改 Roadmap
-   不新增工程目录
-   不调整 Prompt 生命周期
-   不重新规划 PR 编号

仅输出 Framework 文档。

------------------------------------------------------------------------

### 五、完成后

输出：

-   Framework 文档
-   EXEC
-   验收结果

除此之外不修改任何已有工程结构。

------------------------------------------------------------------------

### 六、验收标准

完成后确认：

-   Framework 能支持整个八卷内容生产；
-   后续 PR-012～PR-090 可直接基于该 Framework 执行；
-   不需要再次设计内容生产规范。

全部通过后，将 PR-011 标记为 Approved。
