## 状态定义

- 草稿：仅完成构想，尚未具备执行条件。
- 待执行：Prompt 已准备好，等待执行。
- 执行中：Prompt 正在执行，尚未完成验证。
- 已执行：执行已完成，等待人工 Review。
- 已审核：执行结果已由人工确认。
- 已废弃：Prompt 已停止使用，仅保留审计记录。

## 维护规则

1. 新增或迁移 Prompt 时同步更新本索引。
2. Prompt 版本变化时更新“当前版本”和备注，不覆盖历史执行记录。
3. Prompt 执行后在 `docs/00-project/prompt-history.md` 中追加实际文件映射。
4. 文件尚未创建时必须在备注中明确说明，不能把规划项描述成已存在文件。
5. 废弃 Prompt 保留索引项并将文件迁移到 `archive/`。
