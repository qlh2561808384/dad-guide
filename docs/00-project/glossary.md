# 术语表

## 用途

本文件用于统一项目中的术语、英文名称、缩写和表达边界。当前仅建立模板，不登记孕期、生产、月子或育儿业务术语。

## 维护规则

1. 术语首次进入正式文档前先登记。
2. 定义应简短、可复用，不在术语表中展开业务知识。
3. 涉及医学含义的术语必须记录权威来源并经过人工 Review。
4. 同义词应指定一个推荐写法，其他写法记录在“替代或禁用表达”列。
5. 修改术语后检查所有引用章节，避免不同模块使用冲突定义。
