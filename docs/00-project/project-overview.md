# 项目概览

## 项目背景

本项目为一个生活在杭州、即将迎来第一胎的中国家庭建立长期维护的家庭知识库。家庭主要照护成员为夫妻两人；生产期间虽会使用一对多护工服务，爸爸仍需承担主要协调、学习、护理和记录职责。

## 项目目标

- 建立从孕晚期到宝宝一岁的结构化操作手册。
- 让爸爸能够快速定位当前阶段的任务、流程和记录入口。
- 以 Markdown 作为唯一源文件，通过 Git 保留变更历史。
- 为后续生成 PDF、Word 等格式提供稳定、可转换的内容结构。
- 支持家庭根据实际经历持续补充、校正和迭代。

## 使用方式

1. 先通过 `module-overview.md` 判断当前所处阶段。
2. 进入对应模块的 `README.md` 查找章节。
3. 按章节中的流程、Checklist 和记录区域使用内容。
4. 使用 `templates/` 下的模板保留阶段性记录。
5. 修改前查阅 `writing-standard.md`，修改后通过 Git 提交。

## 文档定位

本项目定位为家庭协作和信息整理工具，不是育儿百科，也不能替代医生、护士或其他专业人员的判断。业务章节后续应优先提供时间节点、操作流程、风险提示、Checklist 和记录入口，避免空泛叙述与未经核验的结论。
