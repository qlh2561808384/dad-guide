# 第一卷：孕晚期准备

## 模块介绍

本模块面向第一次迎接新生命、主要由夫妻两人协作的家庭，组织孕 32 周至进入生产当天流程前的准备工作，重点帮助爸爸完成信息、物资、技能和协作准备。

## 模块目标

- 按真实任务顺序建立孕晚期准备入口。
- 明确爸爸在产检、医院、物资和家庭协作中的执行职责。
- 为后续扩展 SOP、Checklist、流程图和记录表提供稳定章节边界。
- 在临产信号识别与生产当天现场流程之间建立清晰交接点。

## 章节导航

1. [孕晚期概览](third-trimester-overview.md)：说明本卷适用阶段、准备范围和家庭角色切换。
2. [产检管理](prenatal-checkup-management.md)：组织孕晚期产检计划、检查记录和医生沟通准备。
3. [医院准备](hospital-preparation.md)：管理生产医院信息、路线、联系方式、证件与入院前确认事项。
4. [待产包](hospital-bag.md)：管理妈妈、宝宝、爸爸和住院所需物资。
5. [爸爸能力训练](father-skills-training.md)：安排宝宝出生前需要完成的基础照护学习和陪护演练。
6. [临产信号与行动](labor-signs-and-actions.md)：组织临产信号的观察、记录、联系医院和出发决策。
7. [家庭协作计划](family-coordination-plan.md)：安排请假、工作交接、护工和家庭联络机制。

## 内容边界

- 本卷止于识别临产信号、联系医院并决定出发，不展开到院后的生产现场流程；后续衔接[第二卷：生产当天](../02-labor-day/README.md)。
- 爸爸能力训练只安排产前学习与演练，不展开宝宝出生后的实际日常护理；相关内容归入[第五卷：新生儿护理](../05-newborn-care/README.md)。
- 家庭协作计划只处理孕晚期至临产前的安排，不重复[第六卷：爸爸指南](../06-dad-guide/README.md)中的长期角色与协作内容。
- 本卷不承载住院期间管理、妈妈产后恢复或新生儿护理正文。
