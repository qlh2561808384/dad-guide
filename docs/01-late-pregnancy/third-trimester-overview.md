# 孕晚期概览

## 写给爸爸的话

进入孕晚期，爸爸的任务不是替妈妈判断身体情况，也不是把所有风险都背下来，而是让家庭在需要行动时不慌乱。

你要做的是把零散的事情变成可靠的安排：知道下一次产检是什么时候，知道资料和物品放在哪里，知道妈妈希望获得什么支持，也知道出现异常时联系谁、去哪里。

准备得好，不等于能够预测生产何时开始；它意味着变化发生时，家庭仍能清楚沟通、及时求助并完成交接。

## 本章目标

读完本章后，爸爸应当能够：

- 说清医学上的孕晚期与本手册执行范围。
- 理解妈妈、宝宝和家庭角色正在发生的变化。
- 找到第一卷六项重点准备工作的入口。
- 建立每周推进、每日沟通和异常升级的基本节奏。
- 使用 Checklist 和记录表检查家庭准备进度。

本章是第一卷的总入口，不展开产检项目、待产包明细或临产判断细节。

## 什么是孕晚期

### 医学定义

国家卫生健康委员会发布的孕产期保健规范将妊娠 28 周及以后定义为孕晚期。这个阶段仍需按医生安排完成产前检查，并持续关注孕妇健康、胎儿生长发育和宫内情况。[CN-NHC-2011-001]

### 本手册的执行范围

本手册第一卷聚焦**孕 32 周至进入生产当天流程前**。医学定义从 28 周开始，而本卷选择 32 周作为集中准备起点，两者并不冲突：

- 孕 28 周及以后：按建档医院要求完成孕晚期保健。
- 孕 32 周及以后：集中完成医院、物资、能力和家庭协作准备。
- 出现需要联系医院并出发的临产或异常信号后：转入[第二卷：生产当天](../02-labor-day/README.md)。

> 实际孕周、预产期、产检频次和分娩安排，以建档医院记录及产科医生意见为准。

## 为什么重要

孕晚期不是单纯“等待生产”的阶段。保健重点已经包括持续产检、胎动观察、分娩前心理准备、临产先兆教育以及新生儿照护准备。[CN-NHC-2011-001]

对第一次迎接宝宝、主要依靠夫妻两人协作的家庭，这段时间最适合完成三种转换：

- 从“知道要准备”转换为“已经落实负责人和完成日期”。
- 从“遇事再查”转换为“已经保存医院要求、路线和联系方式”。
- 从“爸爸帮忙”转换为“爸爸主动承担协调、记录和执行职责”。

爸爸越早把信息和任务整理好，妈妈越不需要在疲惫或不舒服时反复提醒、解释和收尾。

## 孕晚期爸爸需要建立的认知

### 妈妈的变化需要被听见

孕晚期可能伴随体力、睡眠、活动舒适度和情绪上的变化，但每个人的体验不同。爸爸不要用其他人的孕期经历判断妈妈“正不正常”，也不要把所有不适都归为“孕晚期都这样”。

更可靠的做法是：

1. 先听妈妈完整描述感受。
2. 记录开始时间、变化和是否影响日常活动。
3. 对照医生已经给出的观察要求。
4. 不确定时联系建档医院确认。

### 宝宝仍需要持续关注

宝宝仍在生长发育，产检会继续评估胎儿生长和宫内情况。胎动是家庭能够直接关注的重要变化之一，但家庭观察不能替代产检或医务人员评估。[CN-NHC-2011-001]

不要因为“空间变小，所以胎动理应减少”而自行解释胎动变化。只要妈妈对胎动有担忧，或感觉胎动减少、停止或明显不同于平时，就应及时联系产科评估。[CN-NHC-2020-002][INT-NICE-2021-001]

家用胎心设备的一次正常结果不能排除异常，也不能替代产检。[CN-NHC-2020-002][INT-WHO-2025-001]

### 家庭角色正在转换

| 角色 | 主要职责 | 不应承担的职责 |
| --- | --- | --- |
| 妈妈 | 表达身体感受、意愿和需要；参与医疗决定 | 独自记住全部任务、资料和医院流程 |
| 爸爸 | 协调、记录、准备、沟通、陪同和执行 | 替妈妈描述感受或替医务人员作医疗判断 |
| 医生、护士 | 检查、评估并给出诊疗和护理意见 | 替家庭完成请假、物资和日常协作安排 |
| 护工 | 在服务范围内提供辅助 | 取代爸爸的持续协调责任或医院专业判断 |

妈妈是自身感受、身体和医疗决定的主体。爸爸的主动，不是替妈妈做主，而是减少她承担的信息和执行负担。

### 准备的目标不是预测

预产期是安排准备工作的时间参照，不是宝宝一定出生的日期。家庭不需要反复猜测“到底哪天生”，而应确保无论变化何时出现，都能找到资料、联系医院、完成出发和家庭交接。

## 操作流程

### 每周准备循环

1. 与妈妈进行一次不被打断的状态沟通，先听她当前最需要解决的事情。
2. 查看下一次产检和本周固定安排，确认是否存在时间冲突。
3. 从六项准备领域中选择本周要完成的具体任务。
4. 为每项任务写明负责人和完成日期。
5. 验证已经完成的结果，例如实际拨打或保存电话、走一遍路线、检查物品位置。
6. 将医生交代、妈妈反馈和家庭决定记录在对应表格中。
7. 出现异常时暂停普通准备任务，先按医疗风险提醒升级。

### 每日十分钟沟通

爸爸每天用十分钟确认三件事：

1. 妈妈今天感觉如何，有没有与平时不同或令她担心的变化。
2. 明天是否有产检、工作、采购或需要提前准备的安排。
3. 当前是否有一件事情需要爸爸立即处理，而不是留给妈妈继续提醒。

沟通的目的不是持续盘问症状，而是让妈妈能够随时表达变化，让家庭任务不依赖一个人的记忆。

## 注意事项

- 以建档医院和产科医生针对本次妊娠给出的要求为最高执行依据。
- 不因阅读本手册自行停药、换药、加药或调整检查安排。
- 不用孕肚大小、他人经验、网络图片或单次家用胎心结果判断宝宝情况。
- 不把妈妈的身体信息未经同意扩散到亲友群或无关人员。
- 不把预产期当作固定生产日期，关键准备事项应提前完成。
- 不要求妈妈在不舒服时继续承担采购、路线确认和家庭沟通工作。

## 常见错误

### 常见误区

**误区一：离预产期还有时间，可以等到最后再准备。**

家庭准备包含医院确认、工作交接、物资补齐和技能练习，集中到最后容易造成遗漏。孕 32 周起应按周推进。

**误区二：孕晚期不舒服很常见，所以先忍一忍。**

常见不适和需要就医的异常可能在主观感受上相似。爸爸不负责鉴别；只要出现新的、持续的、加重的或令妈妈担心的变化，就应按医生要求咨询。

**误区三：宝宝空间小了，胎动减少是正常的。**

不要自行用“空间变小”解释胎动减少或明显变化。妈妈对胎动有担忧时，应及时联系产科评估。[CN-NHC-2020-002][INT-NICE-2021-001]

**误区四：家用胎心听起来正常，就可以继续在家观察。**

单次听到胎心不能排除异常，也不能替代产检或对胎动变化的专业评估。[CN-NHC-2020-002][INT-WHO-2025-001]

**误区五：爸爸准备好待产包就完成任务了。**

待产包只是一个领域。联系方式、路线、证件、工作交接、技能演练和异常升级同样需要提前落实。

**误区六：爸爸主动负责，就应该替妈妈决定。**

爸爸负责整理信息和执行协作，但妈妈有权表达感受、偏好并参与医疗决定。爸爸应帮助妈妈与医务人员清楚沟通。

## 医疗风险提醒

### 就医与风险提醒

> 本章用于家庭健康教育、行动准备和记录，不提供诊断或个体化治疗。用药、检查、分娩和护理方案应由具备资质的医务人员结合实际情况决定。出现危险信号时，应立即联系医疗机构或呼叫 120，不要等待家庭护理见效。

| 行动级别 | 可观察情况 | 爸爸立即做什么 |
| --- | --- | --- |
| 日常观察 | 妈妈没有新的异常或担忧，日常状态与医生已说明的情况一致 | 记录变化并按原计划完成产检和家庭准备 |
| 建议咨询 | 出现新的、持续的或反复的不适，妈妈不确定是否需要就医，或家庭无法理解医生此前的观察要求 | 联系建档医院或产科，原样说明症状、开始时间和变化，按回复行动 |
| 立即就医 | 阴道出血、疑似破水或持续阴道流液、胎动减少或明显异常、高热、明显头晕或头痛、视物不清、持续或明显腹痛，或妈妈感觉情况不对 | 立即联系建档医院或产科急诊，并按指示前往医疗机构；不要等待下一次产检或在家自行判断[CN-NHC-2012-001][CN-NHC-2020-002][INT-WHO-2025-001] |
| 立即急救 | 意识不清、抽搐、呼吸困难、无法安全转运或情况快速恶化 | 立即呼叫 120，同时按急救人员指示处理；不要自行驾车冒险转运 |

怀疑破水时，不需要在家确认“到底是不是”。记录开始时间、液体颜色和气味，立即联系建档医院；是否破膜应由医务人员评估。[CN-NHC-2012-001][INT-NICE-2026-001]

胎动没有适用于所有家庭的单一“正常感觉”。以妈妈平时感受到的模式为背景；一旦妈妈担心胎动减少、停止或明显改变，应及时联系产科，不用家用胎心设备给自己“排除风险”。[CN-NHC-2020-002][INT-NICE-2021-001]

具体临产信号、记录方式和出发交接见[临产信号与行动](labor-signs-and-actions.md)。

## Checklist

### 爸爸行动 Checklist

- [ ] 记录建档医院确认的预产期和当前孕周。
- [ ] 确认下一次产检的日期、地点和需要携带的资料。
- [ ] 保存产科门诊、产科急诊和医院总机的有效联系电话。
- [ ] 确认白天前往医院的路线和预计交通方式。
- [ ] 确认夜间前往医院的入口、路线和备用交通方式。
- [ ] 与妈妈共同阅读本章的医疗风险提醒。
- [ ] 约定每天十分钟状态沟通的固定时间。
- [ ] 为第一卷六项准备领域分别指定负责人和完成日期。
- [ ] 将证件、检查资料和医生交代记录放在固定位置。
- [ ] 核对待产包、能力训练和家庭协作章节的未完成事项。
- [ ] 记录一名紧急备用联系人及其可提供的具体帮助。
- [ ] 每周复盘一次未完成任务并更新截止时间。
