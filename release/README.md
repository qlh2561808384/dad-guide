# 发布目录

## 目录用途

本目录保存由 Markdown 源文件生成的 PDF、DOCX 等发布产物。源内容始终在 `docs/` 中维护，不直接编辑发布文件。

## 版本目录

| 目录 | 用途 | 状态 |
| --- | --- | --- |
| `v0.1.0-engineering/` | Phase 0 工程冻结版本 | 目录已建立，尚未生成发布文件 |
| `v1.0.0/` | 第一版正式内容 | 预留 |
| `latest/` | 最新发布版本的副本 | 当前为空 |

## 维护规则

- `latest/` 永远保存最新发布版，内容应与当前最高有效版本一致。
- `vX.Y.Z/` 保存对应历史版本，发布后不得直接覆盖。
- 每个版本分别使用 `pdf/` 和 `docx/` 保存生成文件。
- 空目录使用 `.gitkeep` 保留。
- 发布动作必须登记到 `docs/00-project/prompt-history.md`。
- 本目录中的 PDF、DOCX 是派生产物，不能替代 Markdown 源文件。
